# SkillBag Docs Sustainability

SkillBag Docs supports the SkillBag ecosystem by providing reusable skills for
document-heavy workspaces.

## Funding Goals

Funding for this repository should support:

- maintenance of existing document skills
- tests and fixtures for document behavior
- documentation and examples
- security review of file conversion and OCR workflows
- compatibility updates as the core standard evolves
- development of reference workflows for common PDF and office-document tasks

## Relationship to Core Funding

The core standard should remain freely implementable. Funding this repository
supports practical document tooling around the standard, not exclusive access
to the standard itself.

If formal sponsorship or membership is created, it should be coordinated with
the core SkillBag sustainability model.

## Commercial Work

Commercial services may be built around these skills, including:

- custom document workflow skills
- OCR and extraction pipeline design
- workspace document normalization
- enterprise policy and conformance preparation

Commercial services should not imply that document-skill behavior is normative
unless that behavior is also defined by the core `SKILLBAG.md` specification.
